A glass-box classifier for FTIR identification of plastics

Accuracy parity on accepted specimens, with the referral rate stated rather than hidden. Every chart on this site is drawn from the same result tables as the article, and each one can be downloaded as a print-resolution image or as the data behind it.

Supporting material for an article submitted to IEEE Access. Data: FTIR-Plastics (Zenodo 10736650) and a recyclate FTIR archive (Zenodo 21822279), both CC BY 4.0. Code and tables: github.com/s-matysik/glassbox-ftir. This page needs no network access once downloaded.
